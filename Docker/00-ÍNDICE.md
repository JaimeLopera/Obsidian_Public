# 00 - Índice

> [!info] Docker
> Docker permite empaquetar una aplicación junto con todo lo que necesita para funcionar (sistema base, librerías, configuración) en una unidad llamada **contenedor**. Así funciona igual en tu ordenador, en el de un compañero y en un servidor.

## Orden recomendado

1. Empieza por **Fundamentos** para entender la idea.
2. Sigue con **Imágenes y contenedores** para practicar los comandos.
3. Aprende el **Dockerfile** para construir las tuyas.
4. Añade **Volúmenes y redes** cuando necesites guardar datos o conectar servicios.
5. Termina con **Docker Compose** para proyectos con varias piezas (por ejemplo, web + base de datos).
