# 00 - Índice de JavaScript

> [!info] ¿Qué es esta carpeta?
> JavaScript es el lenguaje que le da vida a las páginas web. Con HTML se pone el contenido, con CSS se le da estilo y con JavaScript se consigue que la página **reaccione**: que un botón haga algo, que se muestren datos nuevos, que un formulario se compruebe, etc.
> Esta carpeta explica JavaScript desde cero hasta lo moderno, y sirve tanto para repasar rápido como para volver a aprenderlo si se te ha olvidado.

---

## 1. Cómo usar esta carpeta

- Si **no te acuerdas de nada**, sigue las notas en orden, del 01 al 19.
- Si **solo quieres repasar algo**, ve directo a la nota del tema y lee el resumen del final.
- Si **tienes prisa**, abre la [[19 - Referencia rápida]].
