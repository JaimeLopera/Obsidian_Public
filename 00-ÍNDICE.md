# HTML - Índice

> [!info] ¿Qué es esta sección?
> **HTML** (*HyperText Markup Language*) es el lenguaje de marcado que da **estructura y significado** al contenido de una página web: define qué es un título, un párrafo, un enlace, una imagen o un formulario. No es un lenguaje de programación, porque no tiene lógica ni cálculos. Describe el contenido y deja el aspecto a [[CSS/00 - Índice|CSS]] y el comportamiento a [[JavaScript/00 - Índice|JavaScript]].

Esta sección reúne todo el HTML necesario para trabajar con soltura. Cada nota sirve como **repaso rápido** si ya conoces el tema y como **explicación desde cero** si lo has olvidado por completo.

---

## 1. Antes de empezar

No necesitas conocimientos previos para empezar con HTML. Solo necesitas:

- Un editor de código (por ejemplo, VS Code).
- Un navegador moderno (Chrome, Firefox, Edge).
- Saber crear y abrir un archivo `.html`.

> [!tip] Cómo usar este índice
> Si es tu primera vez, sigue las notas **en orden**. Si buscas algo concreto, ve directamente a la nota desde la tabla o desde la sección [[#4. Acceso rápido por necesidad|acceso rápido]].
